# Dataset attribution

Almeida, T. & Hidalgo, J. (2011). **SMS Spam Collection** [Dataset].
UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84.

- Official page: https://archive.ics.uci.edu/dataset/228/sms+spam+collection
- Download: https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- The training command downloads the original `SMSSpamCollection` file without modification when it is absent.
- Training-time transformations: whitespace/case normalization for duplicate keys,
  duplicate removal, train/test split, and TF-IDF feature extraction.
- SHA-256 of the raw file: `7d039a24a6083ed9ef0f806ebad56bbb976e3aeb8de05669173bfdc4996c239d`.

Model performance and application code are this project's outputs and are not
endorsed by the dataset creators.
